# ドットキャラ制作室の自己改善

PowerAI の `powerai-self-improve` から、同じ失敗の再現、検査への昇格、対策の効果確認を移植した。対象は `/Users/kanko/projects/pixel-character-workshop` の制作工程。

1. 利用者の指摘または保存済みの結果から、対象コミット、モデル、元画像と対象コマ、指示と範囲、期待、実際の差分を確認する。観測者を人、AI、機械検査のいずれかで記録する。元画像や認証情報は記録に貼らない。
2. 同じ原因の失敗が繰り返された場合、または検査を通った結果に明確な退行が見つかった場合、`docs/improvement-log.md` に候補を残す。同じ試行のコピーや同じ画面の繰り返し確認を独立した証拠に数えない。
3. 再現できるものは、入力の制約、状態の持ち方、回帰テストの順に原因に合う対策を選ぶ。見た目の採否は元コマと候補を同じ条件で比較し、利用者が確かめた結果を記録する。
4. 同じ入力で修正前後を比較し、問題の解消と保護範囲の画素・透過を確認する。採用、見送り、再現できないものと理由を残す。検査に移した規則は重複記載を整理する。

画面の検証にはヘッドレス Playwright を使う。改善はユーザーの依頼で着手し、既存のプロファイルや監視対象に影響させない。
