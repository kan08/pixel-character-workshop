# ドットキャラ制作室

ゲーム用の立ち絵から待機・歩きのコマを組み、前版と比べながらスプライトシートにするローカルアプリです。[概要設計書](docs/overview.html)

## 起動

Node.js 22 以上で、リポジトリ直下から `npm start` を実行します。[ローカルの制作画面](http://127.0.0.1:4173/)を開くとサンプルが表示されます。外部パッケージのインストールは不要です。

1. サンプルの待機・歩きを再生するか、「新規」から基準画のPNGを取り込みます。
2. 待機・歩きに同じサイズのコマを追加します。歩きには右足前と左足前の接地を指定します。コマの順序と表示時間を調整します。
3. 「比較・採用」で履歴と見比べ、待機・歩きをそれぞれ採用します。
4. 「検品・出力」で画像検査と移動プレビューを確認し、シートPNGとコマ情報JSONを保存します。

「プロジェクトを保存」で画像と採用履歴を含む `.pixel-project.json` がダウンロードされます。「プロジェクトを開く」で作業を再開できます。複数ファイルを取り込んだときは、一覧で再生順を確認してください。

## 初版の範囲

1キャラ・1方向・待機と歩き。枠は最大512×512、各動作32コマまで。足元の座標はコマ左上を原点とし、表示時間はミリ秒です。出力JSONの `rect` はシート上のコマ矩形、`pivot` は各コマ内の共通基準点です。

この段階では既存PNGの取り込みがコマ制作の入口です。AIモデル接続、編集範囲を指定した部分生成、実際のゲームエンジンへの取り込みは次の段階です。移動プレビューはアプリ内での参考表示です。

設計書の根拠になったimozuruの調査レポートは、設計時のCodex作業フォルダに保存しています。

## 開発

`npm test` で採用と履歴、書き出しの配置、プロジェクトの読込を検査できます。
